# 🧾 Tax System in Scala

This project is a challenge to Build a TAX system writin in **Scala** where different products have different tax per state and year.

---

## 📦 Requirements

- [Scala](https://www.scala-lang.org/download/)
- [sbt (Scala Build Tool)](https://www.scala-sbt.org/download.html)

---

## 🚀 How to Run

1. **Clone the repository**
```bash
git clone https://github.com/your-username/tax-system-scala.git
cd tax-system-scala
```

2. **Compile the project**
```bash
sbt compile
```

3. **Run the project**
```bash
sbt run
```

The output will be:
```bash
Total price in CA for 2024: $107.25
```
